Two modes. Zero friction.

Dictation writes for you. Agent mode acts for you.

🗣️

Dictation mode

Speak naturally — fillers stripped, grammar fixed, punctuation added, text typed where you want it. Roughly 4× faster than typing a first draft.

⚡

Agent mode

Speak intent, not clicks. “Send John the latest project deck” finds the file, composes the mail, attaches it, and asks before anything sends.

🧠

Context aware

Knows John → john@company.com, that “next week” means Monday 9:00, and remembers your corrections — “I meant Sarah, not Sara.”

🛡️

Confirms what matters

Emails and meetings ask first. Always / big stuff / never — your call. Passwords and mass-deletes are simply refused.

📋

Visible workflows

Multi-step jobs render a live checklist in the voice bar — found → composed → attached → sent — ticking as each step lands.

🔒

Private by design

No servers, no telemetry, no keys. Speech uses your OS engine; transcripts and data live only in local storage.

How it works

Every utterance becomes structured, inspectable JSON — then action.

1 · Listen⌃ Space or the mic. A waveform answers instantly.
2 · UnderstandIntent + entities + time parsing → JSON you can inspect live.
3 · ActApps open, drafts fill, steps tick. High-impact actions wait for your nod.

Install in 30 seconds

No accounts. No downloads from us. No cost — ever.

🪟 Windows

  1. Download the release zip
  2. Double-click install.bat
  3. Hit ⬇ Install in the app to pin it

🐧 Linux

  1. Download the release zip
  2. Run ./install.sh
  3. “Install” from your browser menu

🖥️ Native overlay

  1. cd desktop && npm install
  2. npm run dist → Setup.exe / AppImage / deb
  3. Always-on-top voice bar, ⌃Space anywhere
