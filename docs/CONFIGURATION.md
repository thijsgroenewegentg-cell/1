# /docs/CONFIGURATION.md

# Every setting in JARVIS

185 settings, all in `config.yaml`, all optional — every one has a
working default. Generated by `python scripts/list_settings.py` straight from
`core.config.DEFAULT_CONFIG`, so the defaults below are the real ones.

Three ways to change any of them:

```bash
# 1. edit config.yaml, then restart
# 2. per run, from the environment
JARVIS_LLM__MODEL=mistral python main.py
# 3. ask JARVIS, for the settings it exposes as tools
```

## user

Who you are, so JARVIS addresses you properly and knows where you are.

| Setting | Default | What it does |
|---|---|---|
| `name` | `"Sir"` | What JARVIS calls you in conversation. |
| `title` | `"sir"` | The honorific used in replies — 'sir', 'ma'am', 'boss', or empty for none. |
| `location` | `"auto"` | Default place for weather and news. 'auto' geolocates by IP. |
| `units` | `"metric"` | 'metric' or 'imperial', used by weather and conversions. |

## llm

The local model: which one, where it runs and how it is sampled.

| Setting | Default | What it does |
|---|---|---|
| `provider` | `"ollama"` | Accepted for compatibility; JARVIS only ever talks to Ollama. |
| `host` | `"http://localhost:11434"` | Where Ollama is listening. Point it at another machine on your LAN if you like. |
| `model` | `"llama3.2"` | The model that answers. llama3.2, mistral, qwen2.5, phi3 … |
| `fallback_models` | `["mistral", "llama3", "llama3.1", …]` | Tried in order when the configured model is not installed. |
| `temperature` | `0.7` | Sampling randomness: lower is steadier, higher is more inventive. |
| `top_p` | `0.9` | Nucleus sampling cut-off. |
| `num_ctx` | `4096` | Context window in tokens. Larger remembers more and costs more memory. |
| `max_tokens` | `700` | Longest single reply, in tokens. |
| `timeout` | `180` | Seconds to wait for the model before giving up on a request. |
| `keep_alive` | `"10m"` | How long Ollama keeps the model in RAM between turns ('10m', '1h', '0'). |
| `router_model` | *(blank)* | A smaller model used only for intent classification. Blank reuses the main one. |
| `stream` | `true` | Stream the reply token by token, so speech can start before it finishes. |
| `retries` | `2` | Retry attempts when a request fails. |
| `retry_backoff` | `0.75` | Seconds multiplied per retry. |
| `warm_up` | `true` | Load the model at start-up so the first answer is not slow. |

## voice

Wake word, speech recognition, speech synthesis and voice activity detection.

| Setting | Default | What it does |
|---|---|---|
| `enabled` | `true` | Whether the voice pipeline starts at all. |
| `wake_word` | `"jarvis"` | The word that wakes JARVIS; mishearings of 'jarvis' count too. Leave it blank to need no wake word at all. |
| `engine` | `"auto"` | Wake-word engine: 'auto', 'porcupine', 'openwakeword', 'whisper', or 'none' to switch the wake word off and answer anything you say. |
| `porcupine_access_key` | *(blank)* | Free Picovoice key for the low-power detector. Optional. |
| `porcupine_keyword` | `"jarvis"` | Which built-in Porcupine keyword to listen for. |
| `sensitivity` | `0.6` | Wake-word sensitivity: higher wakes more eagerly and misfires more. |
| `interrupt` | `true` | Let a new utterance cut JARVIS off mid-sentence. |
| `chime` | `true` | Play a short sound when the wake word fires. |
| `stream_speech` | `true` | Speak sentence by sentence while the answer is still being written. |
| `conversation_mode` | `true` | Follow-up questions need no wake word. |
| `conversation_timeout` | `20` | Seconds of silence before the wake word is needed again. |
| `openwakeword.model` | `"hey_jarvis"` | openWakeWord model name, e.g. 'hey_jarvis'. |
| `openwakeword.threshold` | `0.5` | Detection threshold for openWakeWord. |
| `openwakeword.inference_framework` | `"onnx"` | 'onnx' or 'tflite'. |
| `stt.model` | `"base.en"` | Whisper size: tiny, base, small, medium, large — speed against accuracy. |
| `stt.device` | `"auto"` | 'auto', 'cpu' or 'cuda' for transcription. |
| `stt.compute_type` | `"auto"` | Precision, e.g. 'int8' on CPU or 'float16' on a GPU. |
| `stt.language` | `"auto"` | Force a transcription language, or 'auto' to detect. |
| `stt.beam_size` | `1` | Whisper beam search width. 1 is fastest. |
| `stt.vad_filter` | `true` | Let Whisper drop silence before transcribing. |
| `tts.voice` | *(blank)* | Edge-TTS voice name. Blank picks one to match the language. |
| `tts.rate` | `"+8%"` | Speaking rate, e.g. '+8%' or '-10%'. |
| `tts.volume` | `"+0%"` | Speech volume offset, e.g. '+0%'. |
| `tts.pitch` | `"+0Hz"` | Pitch offset, e.g. '+0Hz'. |
| `tts.cache` | `true` | Cache synthesised audio so repeated phrases are instant. |
| `vad.sample_rate` | `16000` | Microphone sample rate in hertz. |
| `vad.frame_ms` | `30` | Audio frame size for voice detection. |
| `vad.energy_threshold` | `0.014` | Loudness above which audio counts as speech. Raise it in a noisy room. |
| `vad.silence_ms` | `900` | Silence that ends an utterance. |
| `vad.min_speech_ms` | `250` | Shorter bursts than this are treated as noise. |
| `vad.max_command_seconds` | `15` | Longest single spoken command. |
| `vad.listen_timeout` | `8` | Seconds to wait for you to start speaking after the wake word. |

## Environment overrides

Any setting can be overridden for one run. Both spellings work — the double
underscore is the documented form, and the single underscore is resolved
against the settings that actually exist:

```bash
JARVIS_LLM__MODEL=mistral python main.py
JARVIS_VOICE__ENABLED=false python main.py --cli
JARVIS_LOGGING__LEVEL=DEBUG python main.py --say 'system stats'
```
